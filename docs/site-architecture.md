# HaiwaiLab.com 全站架构规划

> 版本：v1.0（2026-08-11）
> 定位：内容引流型转化站 —— 不是传统机场站，而是以 AI 工具、海外 App、账号教程、网络问题为流量入口，以机场推荐、机场评测和品牌注册为最终商业转化目标。

---

## 一、商业模型与用户路径

```
获取大流量 → 解决问题 → 建立信任 → 引导网络解决方案 → 机场评测 → 注册转化
   (TOFU)      (TOFU)      (MOFU)         (MOFU)          (BOFU)     (¥¥¥)
```

| 漏斗层级 | 角色 | 内容类型 | 商业目标 |
|---------|------|---------|---------|
| **TOFU 流量层** | 引流 | AI 工具教程、海外 App 教程、账号注册、网络故障排查 | 抢占高搜索量关键词，获取自然流量 |
| **MOFU 信任层** | 承接 | 科学上网入门、客户端教程、协议科普、安全指南 | 让用户意识到"需要一个稳定的网络方案"，建立专业信任 |
| **BOFU 转化层** | 变现 | 机场推荐榜单、单品牌评测、对比评测、优惠码 | 促成注册转化（affiliate 链接） |

**核心原则：每一篇文章都必须知道自己处于漏斗哪一层、下一跳指向哪里。** 没有下一跳的内容不发布。

## 二、栏目结构（信息架构）

```
HaiwaiLab.com
├── /                     首页（榜单强导流 + 最新内容）
├── /ai/                  AI 工具        [TOFU 主引流]
├── /apps/                海外应用       [TOFU 主引流]
├── /accounts/            账号教程       [TOFU 主引流]
├── /network/             网络问题       [TOFU 高意图引流]
├── /guide/               科学上网教程   [MOFU 信任承接]
├── /reviews/             机场评测       [BOFU 转化]
│   ├── /reviews/best/    机场推荐总榜   [★ 核心 Money Page]
│   ├── /reviews/<brand>/ 单品牌评测
│   └── /reviews/vs/      对比评测
└── /deals/               机场优惠码     [BOFU 高转化捕获]
```

### 各栏目定义

**1. `/ai/` AI 工具**（TOFU）
- 二级分类：ChatGPT ｜ Claude ｜ Gemini ｜ Midjourney ｜ AI 视频/绘画 ｜ AI 充值付费
- 典型内容：注册教程、订阅/充值教程、"打不开/被封"排查、Plus/Pro 值不值
- 下一跳：网络前提 → `/guide/` 或直接 → `/reviews/best/`

**2. `/apps/` 海外应用**（TOFU）
- 二级分类：流媒体（Netflix/Disney+/YouTube）｜ 社交（TikTok/Instagram/Telegram/X）｜ 音乐（Spotify）｜ 游戏/其他
- 典型内容：怎么看/怎么用/怎么订阅、地区限制解除、外区账号
- 下一跳：解锁需求 → 流媒体解锁机场榜 → 品牌注册

**3. `/accounts/` 账号教程**（TOFU）
- 二级分类：Google ｜ Apple ID 外区 ｜ 海外手机号/接码 ｜ 虚拟信用卡 ｜ PayPal/支付
- 典型内容：注册流程、验证问题、封号申诉
- 下一跳：注册需要干净 IP → `/guide/ip-quality/` → 机场评测

**4. `/network/` 网络问题**（TOFU，意图最强的引流栏目）
- 典型内容："XXX 打不开怎么办"、节点/延迟/掉线排查、DNS 污染、被墙检测
- 特点：搜这些词的用户离转化只差一步，**CTA 密度可以最高**
- 下一跳：直接 → `/reviews/best/` 或对应场景榜

**5. `/guide/` 科学上网教程**（MOFU）
- 二级分类：入门指南 ｜ 客户端教程（Clash/sing-box/Shadowrocket/V2rayN）｜ 协议科普 ｜ 安全与隐私
- 作用：建立专业信任，是 TOFU → BOFU 的中转站
- 下一跳：每篇文末 + 文中 → `/reviews/best/`

**6. `/reviews/` 机场评测**（BOFU，Money Pages）
- `best/`：总榜 + 场景榜（便宜机场榜、高端机场榜、流媒体解锁榜、ChatGPT 专用榜、游戏加速榜）
- `<brand>/`：单品牌深度评测（测速数据、解锁能力、价格表、优惠码、注册按钮）
- `vs/`：A vs B 对比评测（截获"XX和XX哪个好"搜索词）

**7. `/deals/` 机场优惠码**（BOFU）
- 聚合各品牌当前优惠码/促销活动，天然高转化页，节假日（黑五/双十一/春节）流量爆发

## 四、内链与 CTA 设计规则

### 内链铁律（写进每篇文章的 checklist）

1. **TOFU 文章**：
   - 文中自然位置 1 处上下文链接 →「前提条件：你需要一个稳定的网络环境」→ `/guide/` 入门文 或 `/reviews/best/`
   - 文末固定 CTA 卡片 → 对应场景榜（AI 文→ChatGPT 榜；流媒体文→解锁榜）
2. **MOFU 文章**：
   - 文中 ≥1 处 + 文末 CTA → `/reviews/best/`
   - 客户端教程中"订阅链接哪里来"→ 榜单
3. **BOFU 评测/榜单**：
   - 每个品牌区块内注册按钮（affiliate 链接，`rel="sponsored"`）
   - 单品牌评测 ↔ 总榜互链；评测 → `/deals/` 优惠码
4. **全站固定位**：
   - 侧边栏：机场推荐 TOP3 小卡片（全站展示）
   - 导航栏：「机场推荐」高亮入口
   - 首页首屏：总榜入口 + 本月推荐

### CTA 文案分层（信任感递进，避免硬广感）

| 位置 | 文案风格 | 示例 |
|------|---------|------|
| TOFU 文中 | 顺带提及 | "本教程需要科学上网环境，不知道怎么选可以看这份[机场推荐榜单]" |
| MOFU 文末 | 专业建议 | "我们长期实测了 20+ 家机场，这是当前最值得入手的几家 →" |
| BOFU 按钮 | 直接行动 | "官网注册（含 X 折优惠码）" |

## 五、页面模板

| 模板 | 用于 | 关键组件 |
|------|------|---------|
| 文章页 | TOFU/MOFU | 目录 TOC、更新日期、文中 CTA 组件、文末推荐卡、相关文章 |
| 评测页 | 单品牌 | 评分卡（速度/解锁/稳定/性价比）、套餐价格表、测速截图、优惠码框、注册按钮、FAQ |
| 榜单页 | 总榜/场景榜 | 排名卡片（logo+一句话点评+价格+按钮）、对比表格、选购指南、更新日期 |
| 栏目页 | 各栏目首页 | 分类导航、精选置顶、文章列表 |
| 首页 | / | 首屏榜单入口、场景导航（我要看Netflix/我要用ChatGPT…）、最新文章 |

**SEO 技术要求**：静态生成（速度快）、每页独立 title/description、文章 Schema（Article/Review/FAQ）、sitemap、榜单和评测页标注"最后更新时间"（时效性词如"2026"需定期刷新）。
