**直接答案：白天快晚上慢，说明节点本身没问题，堵的是「路」——晚高峰国际公网出口拥堵 + 机场超售是两大主因。当下可以换冷门地区节点缓解；但根治只有一条路：换走 IEPL/IPLC 内网专线的机场，专线不经公网出口，晚高峰不受影响。**

## 为什么偏偏是晚上卡

20:00–23:00 全国用户同时在线，拥堵发生在三层：

| 层面 | 说明 | 用户能否解决 |
| ---- | ---- | ---- |
| 国际公网出口 | 所有普通中转流量都挤这条路 | ❌ 结构性问题 |
| 机场超售 | 带宽卖给过多用户，高峰不够分 | ❌ 换家才能解决 |
| 单节点过载 | 个别热门节点人太多 | ✅ 换节点即可 |

**自查归属**：换几个不同地区的节点测一下——

- 只有个别节点慢 → 单节点过载，换节点解决
- 所有节点同步掉速、每天固定时段发作 → 出口/超售问题，继续往下看

## 当下缓解（治标）

1. **换冷门地区**：香港节点用户最多，晚高峰换新加坡、日本、美国试试
2. **换协议**：部分线路对不同协议的 QoS 策略不同，SS/VLESS/Trojan 各测一次
3. **减并发**：暂停后台下载、云盘同步，减少多设备同时占用
4. **错峰**：大文件下载挪到白天或深夜

这些只能缓解。**线路层的拥堵，用户端没有根治手段**——就像堵车时换车道有限，路就那么宽。

## 根治：换一条不堵的路

IEPL/IPLC 专线的流量从国内入口**通过内网直达海外落地，不经过公网国际出口**。晚高峰拥堵的正是公网出口段——专线在结构上绕开了它。

这就是专线机场「白天晚上一个样」的原因，也是它贵的原因（专线带宽按 Mbps 采购，成本远高于公网转发）。

判断真假专线的方法：**晚高峰实测**。宣称专线但 20 点后腰斩的，就是普通中转。原理与实测榜见 [IEPL 专线机场推荐](/reviews/best/iepl/)。

## 避坑：超售的定价信号

超售无法直接观测，但定价会说话：

- **月付 5 元「不限量」**：带宽有真实成本，这种定价必然超售
- **适度定价 + 流量上限**：成本结构健康的信号
- **老牌 + 用户口碑**：长期没有大规模晚高峰投诉

换到专线机场后，在 20:00–23:00 实测三次以上：掉速 30% 以内为优秀，基本无感为专线达标。买前先月付测一个月再决定长周期。
