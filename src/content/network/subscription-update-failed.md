faq:
  - q: 机场订阅更新失败最常见的原因是什么？
    a: 三大类：① 订阅地址本身需要代理才能访问（机场把订阅域名放在墙外）——先手动连上任一可用节点再更新 ② 链接已失效（机场更换了订阅域名或你重置过订阅）——去后台重新复制 ③ 套餐过期或流量耗尽，服务端返回空配置。
  - q: 订阅导入成功但没有任何节点是怎么回事？
    a: 服务端返回了空列表，通常因为：套餐已过期/流量耗尽（最常见）、订阅链接不完整（末尾字符被截断）、或客户端不支持该订阅格式（需要通用格式的可联系机场客服获取）。先查后台套餐状态，再重新完整复制链接。
  - q: 更新订阅后节点反而消失了怎么办？
    a: 说明这次拉取到了空配置覆盖了旧节点。原因同上（过期/流量尽/链接失效）。先确认套餐状态；如果套餐正常，可能是机场服务端临时故障，等十几分钟re-update，或在客户端里回滚到上一份配置。
  - q: 浏览器直接打开订阅链接显示无法访问，正常吗？
    a: 分两种：部分机场的订阅域名需要代理才能访问，直连打不开属正常，不代表链接坏了；如果连着代理也打不开、且客户端更新报错，才是链接失效，去后台重新复制或联系客服。
  - q: 订阅链接可以分享给朋友吗？
    a: 不要。订阅链接等于你的账号使用权：拿到链接的人可以直接消耗你的流量、占用你的设备数配额，泄漏后还可能被批量爬取。已经泄漏的话，立即在机场后台重置订阅，旧链接即刻作废。
  - q: 为什么机场要频繁更换订阅域名？
    a: 订阅域名暴露在公网，容易被封锁——被封后所有用户都无法更新订阅，所以机场会主动轮换域名并通过公告或站内信通知。这就是「保存官网备用地址和公告频道」重要的原因：域名一换，旧链接作废，你得能找到新的。

**直接答案：订阅更新失败先做三件事——① 手动连上任一可用节点再点更新（订阅域名可能需要代理访问）② 去机场后台重新复制最新链接 ③ 确认套餐未过期、流量未耗尽。三步覆盖绝大多数订阅故障。**

「链接打不开」「导入没节点」「更新后节点消失」「地址无效」本质上是同一类问题的不同表现，排查流程通用，下面按顺序走。

## 先理解：订阅是怎么工作的

订阅链接是一个远程配置地址：客户端访问它 → 服务端验证你的身份 → 返回当前可用的节点列表。所以故障只可能出在三个环节：

| 环节 | 典型故障 |
| ---- | ---- |
| 你 → 订阅地址 | 域名被墙 / 需要代理访问 / 链接复制不完整 |
| 服务端验证 | 套餐过期 / 流量耗尽 / 订阅被重置 |
| 返回配置 | 服务端故障返回空列表 / 格式不兼容 |

## 排查流程

### ① 先连代理再更新

很多机场把订阅域名放在墙外，**直连状态下更新必然失败**。手动选择任何一个还能用的节点连上，再点「更新订阅」。

Clash Verge 用户注意用「通过代理更新」选项；v2rayN 用户如果所有节点都失效，用「更新订阅（不通过代理）」反而可能成功——两个方向都试。

### ② 重新复制链接

去机场官网后台 → 复制最新订阅链接 → 删除客户端里的旧订阅 → 重新导入。注意：

- **完整复制**：链接末尾的 token 字符最容易被截断
- **不要用历史消息里的旧链接**：机场换过域名或你重置过订阅后，旧链接永久作废

### ③ 查套餐状态

后台确认未过期、流量未耗尽。**服务端对无效账号返回空配置**——这就是「导入成功但没有节点」和「更新后节点消失」的头号原因。

### ④ 换客户端格式

仍失败时，可能是订阅格式与客户端不匹配（部分机场默认输出特定格式）。联系机场在线客服索取通用订阅地址，或询问是否支持你的客户端。

### ⑤ 服务端故障

以上全部正常仍拉不到配置：机场订阅服务临时故障或域名刚被封。看公告、联系客服、等几个小时——通常机场会发布新域名。

## 判断标准：怎么算解决了

更新后节点列表出现、且任一节点能通过延迟测试，即为恢复。建议顺手做两件事：

1. **设置自动更新**（间隔 24 小时），避免机场换节点后配置过时
2. **保存官网备用地址与公告频道**，域名轮换时不至于失联

## 注意事项

- **订阅链接 = 账号使用权**，不要分享、不要在公开场合粘贴；泄漏后立即在后台重置
- 不要高频点击更新，部分机场限制拉取频率，触发后会临时拒绝请求
- 如果一家机场频繁换域名却不发公告、客服失联，这是运营质量红灯，参考 [稳定机场榜](/reviews/best/stable/) 换一家省心的
