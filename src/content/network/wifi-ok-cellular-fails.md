faq:
  - q: 为什么 Wi-Fi 能用，手机流量就不能用？
    a: 因为两者走的是完全不同的网络路径：家宽和移动数据的出口、DNS、IPv6 策略、UDP 处理方式都不同。常见具体原因：运营商网络默认走 IPv6 而节点仅支持 IPv4、运营商对 UDP 流量限制更严、蜂窝网络下 DNS 被劫持、或 App 没有蜂窝数据权限。
  - q: 第一步应该查什么？
    a: 先查 App 权限：iOS 在「设置-蜂窝数据」里确认代理客户端允许使用蜂窝数据（很多人 Wi-Fi 下装的 App 默认没开这个权限）；Android 检查是否被省电策略或流量管理限制后台联网。这是最简单也最常被忽略的原因。
  - q: IPv6 为什么会导致流量下连不上？
    a: 国内移动网络普遍 IPv6 优先，如果机场节点只有 IPv4，域名解析出 IPv6 地址后连接就会失败或超时。解决：在客户端设置里关闭 IPv6（小火箭在设置-高级，Clash 系在 DNS 设置），强制走 IPv4。
  - q: 换了节点、关了 IPv6 还是不行怎么办？
    a: 依次尝试：切换节点协议类型（运营商对 UDP 系协议如 Hysteria2 限制更严，换 VLESS/Trojan 等 TCP 系）、在客户端开启 fake-ip 或自定义 DNS（1.1.1.1）避开运营商 DNS 劫持、开关飞行模式重置网络、重启手机。
  - q: 是不是运营商把我限制了？
    a: 运营商不会针对个人「拉黑」，但不同运营商、不同地区基站对代理流量的容忍度确实有差异——同一机场在移动卡上卡顿、联通卡上流畅并不罕见。如果长期只有你的运营商难用，选择做过三网优化的机场是根本解法。
  - q: 什么是三网优化，对手机用户有什么用？
    a: 指机场入口针对移动、联通、电信分别做了线路优化，三家运营商接入质量一致。手机用户经常在 Wi-Fi（家宽）与流量（移动网络）间切换，三网优化能保证两种场景体验一致，本站品牌库中唯兔云明确标注了这一配置。

**直接答案：Wi-Fi 正常、手机流量不行，优先查三处——① App 的蜂窝数据权限是否开启 ② 关闭客户端的 IPv6（移动网络 IPv6 优先，节点常只有 IPv4）③ 换 TCP 系协议节点（运营商对 UDP 限制更严）。这三步覆盖大多数情况。**

## 为什么会有这种「分裂」现象

Wi-Fi（家庭宽带）和手机流量（运营商移动网络）是**两条完全不同的路**：

| 差异点 | 家宽 | 移动网络 |
| ---- | ---- | ---- |
| IPv6 策略 | 多为 IPv4 优先 | 普遍 IPv6 优先 |
| UDP 流量 | 宽松 | 部分地区限制严格 |
| DNS | 可自定义 | 常被运营商劫持 |
| NAT 类型 | 相对开放 | 更严格 |

同一个节点在两种网络下表现不同，完全正常——排查方向就是消除这些差异。

## 五步排查

### ① App 蜂窝数据权限（最容易漏）

- **iOS**：设置 → 蜂窝数据 → 找到你的代理客户端 → 确认开关打开。Wi-Fi 环境下安装的 App 经常没开这个权限
- **Android**：检查省电策略 / 流量管理是否限制了该 App 的后台与流量联网

### ② 关闭 IPv6

移动网络 IPv6 优先 + 节点仅 IPv4 = 解析到 IPv6 地址后连接失败。

- **Shadowrocket**：设置 → 高级 → 关闭 IPv6
- **Clash 系**：DNS 设置中关闭 IPv6 / 开启 fake-ip 模式
- **v2rayN（开热点给手机时）**：路由设置中禁用 IPv6

### ③ 换协议类型

运营商对 UDP 流量限制更严。如果当前用的是 Hysteria2 / TUIC 等 UDP 系协议，切到 **VLESS、Trojan、Shadowsocks 等 TCP 系**节点再试。

### ④ 避开运营商 DNS

蜂窝网络下 DNS 劫持更常见。在客户端里指定 DNS 为 `1.1.1.1` 或 `8.8.8.8`，或开启 fake-ip / DNS 防泄漏。

### ⑤ 重置网络

开关一次飞行模式（强制重新注册网络）→ 无效则重启手机 → 仍无效换个位置测试（个别基站策略差异真实存在）。

## 判断标准

流量下任一节点延迟测出数值、网页可开即解决。建议把有效的设置（关 IPv6、指定 DNS、TCP 协议节点）保存为默认配置，避免下次切流量时重来。

## 长期方案：选对入口的机场

如果你的手机流量长期难用、换设置只能缓解，根源可能在机场入口与你的运营商适配差——不同机场对三大运营商的优化差异明显。两个选择方向：

1. **三网优化机场**：入口对移动/联通/电信分别优化，切换网络体验一致（本站收录品牌中 [唯兔云](/reviews/weituyun/) 明确标注此配置）
2. **多入口机场**：BGP 智能入口自动选择最优路径

## 注意事项

- 排查时每次只改一个设置，否则无法定位有效项
- 公共 Wi-Fi 下的异常不在本文范围（公共网络常主动阻断代理流量，属正常现象）
- 双卡手机注意确认当前生效的是哪张卡的网络
