faq:
  - q: 别人都能用只有我不能用，说明什么？
    a: 说明机场服务端是正常的，问题锁定在三个范围：你的账号状态（设备数超限、流量耗尽）、你这台设备的环境（时间、防火墙、残留配置、DNS 缓存）、或你所在的网络环境（路由器、运营商、公司网络策略）。排查范围一下子缩小了三分之二。
  - q: 什么是设备数超限？怎么判断？
    a: 多数机场限制同时在线设备数（常见 3-5 台）。超限后新设备的连接会被服务端拒绝，表现为其他设备正常、新设备连不上。判断：在机场后台查看在线设备数，断开几台旧设备（或重置订阅踢掉所有设备）后重试。
  - q: 电脑能用但手机不能用（或反过来）怎么排查？
    a: 两台设备对比着查差异项：是否用同一节点、代理模式是否一致、失败那台的系统时间是否准确、是否有防火墙/杀毒/VPN 残留配置。移动网络与 Wi-Fi 的差异（IPv6、UDP 限制）见专文。逐项对齐后通常能定位。
  - q: 公司/学校网络里只有我连不上，怎么回事？
    a: 企业级网络常有更严格的策略：封锁常见代理端口、深度包检测、强制门户认证。先确认已完成网络登录认证；再换协议类型（伪装性强的 Trojan/VLESS 存活率更高）；仍不行说明该网络主动阻断代理流量，属环境限制而非故障。
  - q: 重装客户端有用吗？什么时候该重装？
    a: 在排除了账号配额、系统时间、网络环境后，如果同设备上其他浏览器/应用也异常、配置反复导入失败、客户端行为怪异（开关无效、闪退），重装是合理的最后手段。重装前记得导出或记录订阅链接。
  - q: 怎么彻底重置一台设备的网络状态？
    a: 依次：关闭代理客户端 → 系统网络设置里清除手动代理残留 → 刷新 DNS 缓存（Windows 执行 ipconfig /flushdns，手机开关飞行模式）→ 重启设备 → 重新打开客户端连接。这套组合能清掉绝大多数本机残留问题。

**直接答案：别人正常、只有你连不上，先查两个高频原因——① 设备数超限（机场后台看在线设备，断开旧设备或重置订阅）② 本机环境问题（系统时间、防火墙、残留代理配置）。服务端没问题，排查范围就缩小到账号、本机、所在网络三层。**

「其他用户正常」是重要的诊断信息：机场没挂。接下来三层漏斗定位。

## 第一层：账号配额

### 设备数超限（最高频）

多数机场限制**同时在线设备数**（常见 3–5 台）。超限时服务端拒绝新连接——老设备照常用，新设备死活连不上，症状与你的情况完全吻合。

处理：

1. 机场后台查看当前在线设备数与套餐上限
2. 断开不用的旧设备（旧手机、闲置电脑、路由器插件都算）
3. 快速踢掉全部设备的办法：**后台重置订阅**（所有设备立即掉线，重新导入新链接）

### 流量与套餐

多人合用一个订阅时，流量可能被其他人用完了——后台确认剩余流量。

## 第二层：本机环境

和能用的设备**对比差异**，逐项对齐：

| 检查项 | 说明 |
| ---- | ---- |
| 同一节点？ | 先切到别人正常使用的那个节点 |
| 系统时间 | 偏差几分钟就会 TLS 失败，同步一次 |
| 防火墙/杀毒 | 临时关闭网络防护测试 |
| 残留配置 | 老的 VPN/代理软件残留会抢流量 |
| DNS 缓存 | Windows `ipconfig /flushdns`；手机开关飞行模式 |

**彻底重置组合拳**：关客户端 → 清系统代理残留 → 刷 DNS → 重启设备 → 重连。

客户端特有问题见对应专文：[Clash Verge 超时](/network/clash-verge-timeout/) / [小火箭无法连接](/network/shadowrocket-connection-failed/)。

## 第三层：所在网络

同一订阅、同一设备，换个网络就好了？那是网络环境问题：

- **家庭网络**：重启路由器；检查路由器上的去广告/代理插件是否劫持流量
- **公司/学校网络**：企业防火墙常封代理端口、做深度包检测——先完成上网认证，再换伪装性强的协议（Trojan/VLESS）；仍不行属于环境主动阻断，不是故障
- **移动网络 vs Wi-Fi**：差异分析见 [Wi-Fi 能用流量不能用](/network/wifi-ok-cellular-fails/)

## 判断标准

该设备在与正常设备相同的节点、相同网络下能连通即解决。定位到的差异项（如设备超限）记下来，下次直奔主题。

## 注意事项

- 多人合用订阅本身有风险：互相挤设备配额、流量被消耗、且违反多数机场的服务条款——长期建议各自购买，低价选择见 [便宜机场榜](/reviews/best/cheap/)
