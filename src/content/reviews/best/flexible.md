## 什么人适合不限时套餐

月付套餐的隐藏成本是**浪费**：出差、忙碌、假期不上网的月份，流量照样清零。不限时套餐（流量包永久有效、用完再买）解决的就是这个问题。

三类人最受益：

| 类型 | 为什么适合 |
| ---- | ---- |
| 用量不规律 | 有的月 80GB、有的月 5GB，月付按峰值买浪费 |
| 轻度用户 | 每月只用 10-30GB，月付最低档也用不完 |
| 备用机场持有者 | 平时不用，主力故障时才顶上，月付纯浪费 |

## 划算与否：先算清楚

不限时套餐的单 GB 单价通常**高于**月付套餐，它的价值在于「不浪费」而非「更便宜」。判断方法：

- **稳定每月 80GB 以上** → 月付更划算，见 [便宜机场推荐](/reviews/best/cheap/)
- **每月 20-50GB 波动** → 不限时更省
- **有几个月完全不用** → 不限时明显更优

## 核心风险：跑路

流量包「永久有效」的前提是机场一直运营。所以选不限时套餐时，**运营年限比价格更重要**——本榜单两家都是运营多年的品牌。另外两条纪律：

1. 单次不要囤过大的流量包（分批购买）
2. 优先选有长期运营记录的品牌，判断方法见 [稳定机场推荐](/reviews/best/stable/)
