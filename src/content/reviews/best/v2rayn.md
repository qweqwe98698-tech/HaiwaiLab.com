## 电脑党的核心矛盾：流量不够用

手机用户一个月 50GB 绰绰有余，电脑用户完全是另一回事：

| 场景 | 流量消耗 |
| ---- | ---- |
| 4K 视频 | 约 3GB / 小时 |
| 1080p 视频 | 约 0.7GB / 小时 |
| 大文件下载 / 镜像拉取 | 单次可达数 GB |
| 开发者依赖包、Docker 镜像 | 累积消耗大 |

每天看两小时 4K 就是 180GB/月——100GB 套餐对电脑重度用户往往撑不过半个月。所以本榜单的筛选标准是：

1. **入门套餐月流量 ≥150GB**（来自品牌方公开套餐信息）
2. **实测速度表现良好**（来自各品牌原始测速图）

两项都可在对应品牌评测页核对原始数据。

## v2rayN 用户的额外优势

v2rayN 基于 Xray 内核，协议兼容性最广（VMess / VLESS / Trojan / Shadowsocks / Hysteria2），本站收录机场的订阅均可导入。上榜机场中多家为 VLESS 全节点，配合 v2rayN 的路由规则可以做到：

- **分应用代理**：只让特定程序走代理，其余直连
- **TUN 模式**：全局接管系统流量，解决部分程序不走代理的问题
- **路由规则**：国内直连、国外代理，节省流量
