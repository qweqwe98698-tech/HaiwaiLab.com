## 为什么 Clash 用户该看「节点数量」而不是「是否支持 Clash」

先说结论：**本站收录的 16 家机场全部支持订阅导入 Clash**，所以「支不支持」根本不是筛选条件。

Clash 真正的价值在于它的三个能力——**地区分组切换、自动测速优选、规则分流**。而这三个能力都有一个前提：你的订阅里得有足够多、足够分散的节点。只有 5 个节点的订阅，自动优选没有意义；只覆盖 2 个地区的订阅，地区分组形同虚设。

所以本榜单的筛选标准是：

| 标准 | 门槛 | 数据来源 |
| ---- | ---- | ---- |
| 节点数量 | 测速样本 ≥60 个 | 各品牌原始测速图 |
| 地区覆盖 | ≥10 个国家/地区 | 各品牌原始测速图 |
| 实测速度 | 主力区速度表现 | 各品牌原始测速图 |

排序按实测速度与覆盖广度综合。每家的完整测速图见对应评测页。

## 上榜机场的 Clash 使用建议

- **做地区分组**：把香港、新加坡、日本、美国分成四组，按用途切换（AI 用新加坡/美国，追剧按片库地区）
- **开自动测速**：在每个分组内启用 URL-Test，让 Clash 自动挑当前最快的节点——节点越多这个功能收益越大
- **善用规则分流**：国内直连、国外代理，避免不必要的流量消耗
