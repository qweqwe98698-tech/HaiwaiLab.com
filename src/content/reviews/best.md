## 排名方法：我们怎么测

本榜单 16 家机场全部经过同环境真实测速（联通 5Gbps 家宽、32 线程并发、覆盖各家全部主力地区节点），原始测速图展示在各品牌评测页，数据未做修改。排名综合四个维度：

| 维度 | 权重来源 | 说明 |
| ---- | -------- | ---- |
| 速度 | 实测数据 | 各地区节点延迟 RTT + 平均/峰值下载速度 |
| 解锁 | 品牌方宣称（Vendor Data） | AI 工具（ChatGPT/Claude）与流媒体（Netflix 等）解锁能力，后续逐项验证 |
| 稳定 | 实测 + 运营信息 | 测速波动、线路类型、已知开业年份 |
| 性价比 | 价格数据 | 每月价格 / 流量额度的相对竞争力 |

> 品牌方未提供的信息（运营时间、节点总量）我们标注「未核实」，不做虚构。
