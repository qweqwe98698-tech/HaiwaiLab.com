**直接回答：小火箭的使用分两个阶段——先用外区 Apple ID 买到 App，再粘贴订阅链接连接。** 第一阶段是 iOS 用户特有的门槛（国区已下架），第二阶段只要 1 分钟。

## 第一阶段：下载小火箭

Shadowrocket 已从中国区 App Store 下架，需要**外区 Apple ID**（推荐美区）购买，售价约 2.99 美元。

1. 注册一个美区 Apple ID —— 完整步骤见 [美区 Apple ID 注册教程](/accounts/us-apple-id/)（免信用卡，10 分钟）
2. 在 App Store 中**只切换账号、不要登录 iCloud**（避免设备锁风险）
3. 搜索 Shadowrocket，购买下载

> 提示：保留这个 Apple ID 的账号密码。App 更新时需要切回该账号，日常使用则不受影响。

## 第二阶段：导入订阅并连接

### 导入订阅

**方式一（推荐）**：复制机场提供的订阅链接 → 打开小火箭 → 右上角 **+** → 类型选择 **Subscribe** → 粘贴链接 → 右上角「完成」

**方式二**：部分机场提供订阅二维码，点击小火箭右上角的扫码图标直接扫描

导入后在首页**下拉刷新**，节点列表就会出现。

> 还没有订阅？iOS 用户选机场优先看延迟与稳定性，我们按这个标准筛选了 [Shadowrocket 机场推荐](/reviews/best/shadowrocket/)。

### 连接

1. 选择一个节点（点击节点名右侧的圆圈选中）
2. 打开首页顶部的**总开关**
3. 首次连接会弹出 iOS 的 VPN 配置权限请求，点击「允许」并验证 Face ID / 密码

### 全局路由模式

在首页「全局路由」中选择：

| 模式 | 用途 |
| ---- | ---- |
| 配置 | 按规则分流，国内直连、国外代理（日常推荐） |
| 代理 | 全部流量走代理（排查问题时用） |
| 直连 | 关闭代理 |

## 省电优化（iOS 用户重点）

小火箭耗电主要来自**节点频繁重连**与**自动测速**：

1. **关闭自动测速**或延长测速间隔（设置中调整）
2. **固定一个稳定节点**，不要用自动切换
3. **优先低延迟节点**——延迟低意味着重传少，实际更省电

这也是我们推荐 iOS 用户按「实测延迟」而非「峰值速度」选机场的原因。

## 故障排查

### 显示已连接但无法上网

1. 下拉刷新订阅
2. 「设置-高级」中**关闭 IPv6**（iOS 上 IPv6 泄漏是高频原因）
3. 确认选中的是具体节点而非空的节点组
4. 删除 iOS「设置-通用-VPN 与设备管理」中的旧配置后重连
5. 确认订阅未过期、流量未耗尽

### 节点全部超时

先用手机流量（关闭 Wi-Fi）测试：如果流量下正常，说明是 Wi-Fi 网络环境问题；如果都超时，检查订阅状态或更换节点。

### 无法更新 App

需要切回购买时使用的外区 Apple ID。
