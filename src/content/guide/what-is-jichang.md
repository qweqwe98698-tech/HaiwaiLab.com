## 机场是什么

「机场」指提供订阅链接的代理服务：付费订阅后获得一组节点，导入客户端（因早期客户端 Clash 的 logo 是纸飞机而得名）。

## 常见协议一句话看懂

| 协议 | 特点 |
| ---- | ---- |
| Shadowsocks (SS) | 老牌轻量，速度快 |
| V2Ray/VMess | 功能强，抗封锁更好 |
| Trojan | 伪装 HTTPS 流量，隐蔽性好 |
| Hysteria2 | 基于 QUIC，弱网环境表现好 |

结论：**普通用户不用纠结协议**，主流机场都会混合提供，客户端自动处理。

## 中转与专线：价格差异的来源

- **直连**：便宜，晚高峰易拥堵
- **中转**：国内中转服务器加速，主流方案
- **IPLC/IEPL 专线**：不过公网、不受晚高峰影响，最快最稳，也最贵

2. **测速数据**：看第三方实测而非官网宣传
3. **解锁能力**：按你的需求验证（AI 工具 / 流媒体）
