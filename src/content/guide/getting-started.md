面对跨境办公、文献查阅、海外社交及 AI 工具的使用需求，许多初学者常常被琳琅满目的专业名词和各种代理客户端搞得一头雾水。本指南旨在用通俗语言梳理完整的科学上网逻辑，帮助你在最短时间内搭建起稳定、安全的网络环境。

## 基本原理：为什么需要加密代理

在国内网络环境下直接访问海外互联网时，数据包需要经过国际出口网关。由于防火墙策略（GFW）对敏感 IP、未备案域名以及特定网络协议实施拦截或 DNS 污染，导致目标网站无法打开或连接超时。

科学上网的核心原理，是在国内设备与海外目标服务器之间架设一台处于不受阻断机房的“中转代理服务器”。你的设备将访问请求加密打包发送给代理节点，由代理节点在海外公网代为抓取数据，再通过加密隧道回传给你的客户端。在此过程中，本地网络运营商只能看到加密流量往返，从而绕过了封锁。

## 两种主流方案：机场 vs 商业 VPN

| 维度 | 机场（订阅制网络代理） | 传统商业 VPN（Express/Nord 等） |
| ---- | ---------------------- | -------------------------------- |
| **速度上限** | 极高（IEPL/IPLC 专线可跑满千兆家宽） | 中等（易受国际出口骨干网拥堵限制） |
| **节点数量** | 多（通常 30–80 个全球优质节点） | 少（国内连接入口常遭遇封锁） |
| **流媒体/AI 解锁** | 针对性原生 IP 轮换，解锁率极高 | 机房 IP 容易被 Netflix/OpenAI 批量风控 |
| **客户端生态** | 借助 Clash Verge、小火箭等开源工具分流 | 官方闭源客户端开箱即用 |
| **每月成本** | 普遍更低（7–25 元/月为主力区间） | 普遍更高（单月往往需 10–12 美元） |

对绝大多数国内用户而言，**过境走 IEPL/IPLC 专线的机场是当前综合体验最好、抗晚高峰波动最强的主流选择**。什么是专线机场、如何鉴别线路，可深入阅读：[机场是什么？怎么选？完整科普指南](/guide/what-is-jichang/)。

## 操作系统与客户端选型

根据你的日常主力设备，选择经过社区长期验证的开源或成熟客户端：

- **Windows 电脑**：首选 [Clash Verge Rev 使用教程](/guide/clash-verge-tutorial/)（支持规则分流与 TUN 模式）或 [v2rayN 客户端配置教程](/guide/v2rayn-tutorial/)。
- **macOS 苹果电脑**：推荐 Clash Verge Rev for Mac 或 Surge for Mac。
- **iPhone / iPad**：首选 Shadowrocket（小火箭），需使用外区 Apple ID 下载，详见 [美区 Apple ID 零门槛注册教程](/accounts/us-apple-id/) 与 [Shadowrocket 配置指南](/guide/shadowrocket-tutorial/)。
- **Android 安卓手机**：推荐 FlClash、v2rayNG 或 Clash Meta for Android，配置简单且省电。

## 新手配置三步跑通流程

1. **选择靠谱服务并注册**：前往 [2026 机场推荐排行榜](/reviews/best/) 或 [机场品牌库](/brands/)，挑选一家综合表现优秀且支持月付的主力品牌。
2. **一键导入订阅地址**：在机场用户后台复制你的专属「订阅链接（Clash/V2Ray）」，粘贴至客户端的配置订阅栏目并点击“更新/拉取”。
3. **选择节点并开启系统代理**：在节点列表中展开常用地区（如香港、日本、新加坡），选择延迟最低的节点，并将代理模式设为「规则模式（Rule）」，即可实现国内直连、海外走代理的无感浏览体验。

## 新手避坑与防跑路原则

- **切勿沉迷免费节点**：公开免费节点存在极高的连接限速与频繁断流，且未经鉴权的公共服务器存在流量被中间人窃听篡改的隐私风险。
- **坚守「先月付」原则**：无论官方宣传多么天花乱坠，首次使用都建议先买月付套餐，实测所在地区不同运营商（电信/移动/联通）在晚高峰 20:00–22:00 的真实表现，稳定 1–2 个月后再考虑长周期折扣。
- **警惕超低价不限流量陷阱**：月付 3–5 元宣称“不限时、不限量、千兆高速”的个人小作坊机场，往往靠严重超售维持运营，极易在几个月内因线路亏损或封锁而直接跑路。
