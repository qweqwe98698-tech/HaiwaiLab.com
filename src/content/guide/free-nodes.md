**直接回答：免费节点能连上，但不适合长期使用——它的问题不是「慢」，而是三个结构性缺陷：带宽被无限制瓜分、生命周期极短、运营者身份无法验证。** 临时应急可以用；日常主力、尤其是需要登录账号的场景，风险明显大于省下的那点钱。

## 免费节点从哪来，为什么免费

理解风险要先理解来源。市面上的「免费机场节点」主要有四类：

| 来源 | 免费的原因 | 主要风险 |
| ---- | ---- | ---- |
| 机场官方试用 | 拉新推广，转化付费 | 风险低，但额度小、时效短 |
| 公开分享的订阅 | 个人测试剩余 / 引流 | 随时失效、极度拥挤 |
| 论坛/群组公开节点 | 来源不明 | 无法验证运营者，隐私风险最高 |
| 「免费」实为限时体验 | 短期获客 | 到期即断，需付费续 |

**关键区别**：机场官方提供的试用节点来源明确、服务方可追溯，属于正常商业行为；而公开传播的免费节点，你不知道服务器是谁在运营、为什么愿意承担带宽成本。

## 三个结构性问题

### 1. 带宽必然不够用

服务器带宽是真金白银的成本。免费提供意味着没有付费用户分摊，而节点地址一旦公开就会被大量用户涌入——**晚高峰（20:00–23:00）基本处于不可用状态**。这不是运营者不努力，是成本结构决定的。

### 2. 生命周期极短

公开传播的节点会很快被封锁，多数免费节点的存活时间在几小时到几天之间。这意味着你需要持续寻找、反复配置——**时间成本远高于每月十几元的付费方案**。

### 3. 运营者身份无法验证

这是最容易被忽略的一点。代理服务器天然能看到你的**连接目标**：HTTPS 的内容是加密的，但你访问了哪些网站、什么时间、多大流量，对运营者完全可见。

付费机场至少受商业信誉约束、有可追溯的服务方；来源不明的免费节点没有任何约束机制。

## 特别提醒：不要用免费节点登录账号

除了流量可见性，还有一个更现实的风险：**账号安全**。

免费节点的出口 IP 被大量陌生用户共享，其中难免有触发风控的行为。结果就是：

- Google / Apple ID 触发异常登录验证，严重时临时冻结
- Netflix、银行、支付类服务判定为高风险登录
- ChatGPT 等 AI 服务频繁人机验证甚至限制访问

登录类操作请使用固定、共享程度低的节点。相关原理见 [ChatGPT 打不开排查](/ai/chatgpt-not-working/) 中的 IP 风控章节。
