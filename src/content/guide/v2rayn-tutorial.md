**直接回答：v2rayN 的使用是「解压运行 → 粘贴订阅 → 开启系统代理」三步。** 但相比 Clash Verge，它有一个新手必须知道的前提：**Windows 系统时间必须准确**——时间偏差会导致所有节点超时，这是 v2rayN 用户最高频的故障来源。

## 第一步：下载与安装

1. 从项目官方发布页下载 `v2rayN-windows-64.zip`（含 Xray 内核的完整包）
2. **解压到固定目录**（如 `D:\v2rayN`），不要放在桌面或临时目录
3. 右键 `v2rayN.exe` → 以管理员身份运行（TUN 模式需要）

> 杀毒软件可能误报——代理工具会修改系统网络设置，属正常现象。请从官方发布页下载并加入白名单，不要用第三方修改版。

## 第二步：导入机场订阅

1. 在机场后台复制**订阅链接**（完整复制，末尾易漏字符）
2. v2rayN 主界面 → 菜单栏「订阅」→「订阅设置」
3. 点击「添加」，把链接粘贴到 **地址(url)** 栏，备注随意
4. 确定后回到主界面 → 「订阅」→「**更新订阅（不通过代理）**」

节点列表出现后，按 `Ctrl+A` 全选 → 右键「测试延迟」，挑一个延迟低的双击选中。

> 还没有订阅？电脑端流量消耗大，我们按「150GB 以上大流量 + 实测速度」筛选了 [v2rayN 机场推荐](/reviews/best/v2rayn/)。

## 第三步：开启系统代理

主界面右下角或托盘菜单 → **系统代理** → 选择「**自动配置系统代理**」。

这一步不做的话，节点测速正常但浏览器依然走直连——这是「测速正常却打不开网页」的最常见原因。

## 路由与进阶

**路由模式**：托盘菜单「路由」中选择：

| 模式 | 用途 |
| ---- | ---- |
| 绕过大陆地址 | 日常推荐，国内直连、国外代理 |
| 全局 | 所有流量走代理，排查问题时用 |
| 绕过局域网和大陆 | 同时排除内网地址，家庭网络环境推荐 |

**TUN 模式**：需要管理员权限，可能需安装虚拟网卡驱动。用于让不遵守系统代理的程序（游戏、命令行工具、Docker）也走代理。日常浏览不必开启。

**分应用代理**：在路由设置中可按进程名配置，实现「只让特定程序走代理」。

## 故障排查

### 节点全部超时（最高频）

按这个顺序查，第一条命中率最高：

1. **检查 Windows 系统时间**——设置 → 时间和语言 → 点击「立即同步」。时间偏差超过几分钟会导致 TLS 握手全面失败
2. **订阅链接是否完整**
3. **更新内核**：菜单「设置」→「检查更新」→ 更新 v2rayN 与 Xray 内核
4. **防火墙 / 杀毒软件**：临时关闭网络防护测试
5. **订阅是否过期或流量耗尽**

### 测速正常但打不开网页

- 确认**系统代理**已设为「自动配置系统代理」
- 尝试开启 **TUN 模式**
- 更换 DNS 为 `1.1.1.1`
- 检查浏览器是否装了独立代理插件（会覆盖系统代理）

### 订阅更新失败

- 订阅地址本身需要代理 → 先手动添加一个可用节点连上后再更新
- 链接失效 → 后台重新复制
- 内核过旧不支持新协议 → 更新内核

### 端口被占用

菜单「设置」→「参数设置」中修改本地监听端口（默认 10808/10809），避开冲突程序。
