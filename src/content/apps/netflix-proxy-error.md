**直接回答：Netflix 报「检测到代理」只有一个原因——你的出口 IP 被 Netflix 列入了屏蔽名单。** 这与账号、套餐、设备、客户端都无关，所以不用去折腾重装 App 或换账号，正确方向只有一个：换到未被屏蔽的解锁 IP。

## 先理解屏蔽机制

Netflix 与版权方的协议要求按地区分发内容，因此它长期维护一份数据中心 IP 黑名单：

- **机房 IP**：绝大多数普通节点使用，容易被识别并屏蔽
- **原生 IP / 解锁 IP**：服务商专门采购并持续维护，能通过检测

关键点在于「持续维护」——被封的 IP 需要不断更换，这是流媒体解锁服务成本高的原因，也是选服务时要看这项能力的原因（见 [流媒体解锁机场推荐](/reviews/best/streaming/)）。

## 按错误类型排查

| 症状 | 含义 | 处理 |
| ---- | ---- | ---- |
| 「您似乎正在使用解锁工具或代理」 | IP 被完全屏蔽 | 换节点 |
| 错误码 M7111 / F7111 | 同上（浏览器端） | 换节点 + 清 Cookie |
| 只能看自制剧 | 部分解锁 | 换流媒体专用/原生 IP 节点 |
| 能进首页但播放转圈 | 带宽不足或线路抖动 | 测速，换更快节点 |
| 搜不到某部剧 | 片库地区差异（非故障） | 切换到对应地区节点 |

## 标准处理流程

**第一步：换节点**
优先选择服务商明确标注「流媒体解锁」的节点。同一家服务商的普通节点与流媒体节点解锁能力可能完全不同。

**第二步：清除 Cookie**
清除 netflix.com 相关 Cookie 后重新登录。旧 Cookie 里可能残留上一次的地区判定。

**第三步：排除本地泄漏**
- 关闭 IPv6（IPv6 流量绕过代理会暴露真实 IP，这是很多「换了节点还报错」的隐藏原因）
- 关闭浏览器的广告拦截、隐私保护插件
- 确认代理模式：规则模式下确认 netflix.com 未被分流到直连

**第四步：换设备验证**
用手机流量 + 同一节点测试。若手机能看、电脑不能，说明问题在电脑端配置而非节点。

## 什么时候该换服务商

偶发失效正常，但出现以下情况说明解锁维护能力不足：

- 所有节点都无法解锁，持续多天
- 客服无法提供可用的流媒体节点
- 官方标注支持解锁但实际长期不可用
